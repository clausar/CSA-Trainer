Alpha 2.0

Changelog:
- MAJOR: Changed Service Worker caching strategy
- HTML, CSS, and JS are NEVER cached - always fetched fresh from network
- Only images and manifest are cached for offline support
- Fixes persistent cache issues causing old styles to appear
- Ensures updates are always immediately visible

Previous versions:
- Alpha 1.9: Updated cache busters to force CSS reload
- Alpha 1.8: Improved mobile container width for better space utilization
- Alpha 1.7: Reverted to centered container layout
- Alpha 1.6: Added number key shortcuts (1-9) to select options
- Alpha 1.5: Added keyboard support for Enter key
