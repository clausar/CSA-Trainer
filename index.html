📋 Excel Formatting Rules

✅ Required Columns

Your Excel file must have these two columns in the first row (header):

Question

Contains the question text followed by answer options on new lines.

Answer

Contains the correct answer letter(s) (A, B, C, D, etc.).

📝 Question Format

Each question cell should contain:

What is ServiceNow? A. A cloud platform for IT service management B. A database management system C. A programming language D. An operating system
⚠️ Important:
  • Question text comes first
  • Each option starts with a letter (A, B, C, etc.) followed by a period
  • Options must be on separate lines (use Alt+Enter in Excel)
  • At least 2 options required

✓ Answer Format

The Answer column should contain the correct letter(s):

Single Answer A
Multiple Answers A B

💡 For multiple correct answers, put each letter on a new line (Alt+Enter in Excel)

🎁 Optional Columns

Add these columns for extra features:

Verified

Mark questions as verified/reviewed. Values: true, false, 1, 0

Verified
Deprecated

Mark outdated questions. Values: true, false, 1, 0

Deprecated
Type

Categorize questions (e.g., "CMDB", "Workflows", "Security"). Any text value.

💡 Pro Tips

  • Use Alt+Enter in Excel to create line breaks within a cell
  • Column names are case-insensitive (Question = question = QUESTION)
  • Empty rows are automatically skipped
  • Duplicate questions are detected and skipped in Insert mode
  • Save as .xlsx or .xls format
  • You can add URLs in questions - they become clickable links
